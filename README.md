# capstone

Moldflow 폼사출 해석 결과를 비교하는 발표용 정적 웹사이트입니다. HTML과 로컬 JavaScript/CSS, MP4를 GitHub Pages에서 제공합니다.

## 발표할 때

예시 영상, 버블 거동, 공정변수별 그래프, 상관분석, 예측 모델 순으로 사용할 수 있습니다. 각 화면 오른쪽 위의 **발표 메모**에 설명할 핵심과 조작 방법이 있습니다.

- 그래프의 **조건 3개 비교**는 다른 세 변수를 고정합니다. **수준별 평균**은 해당 수준의 27조건을 평균합니다. **전체 경향**은 나머지 세 변수가 같은 3조건을 한 선으로 연결한 27개 선입니다. 평균은 조건별 차이를 가릴 수 있으므로 전체 경향과 함께 확인합니다. 원자료 81개는 수정하지 않았습니다.
- 상관 히트맵의 칸을 클릭하거나 키보드로 선택하면 해당 두 항목의 81조건 산점도와 상관 강도를 표시합니다. **강도 기준**에서 기존 그림을 볼 수 있습니다. 압력은 평균값입니다. `|r| ≥ 0.4`는 수업의 해석 기준이며 통계적 유의성 판정이 아닙니다.
- 예측 모델의 **예측해 보기**는 현재 입력의 네 출력값을 표시합니다. 저장된 동일 조건이 있으면 참고 해석값도 표시합니다. **성능 확인**은 학습에 사용하지 않은 25조건에서 세 모델을 비교합니다. 두 화면은 목적이 다르며, 입력을 바꿔도 평가 데이터는 바뀌지 않습니다.
- 결정트리의 실제 분기 구조는 **예측해 보기**에서 출력 항목을 선택해 확인합니다. 모델 개념도는 학습된 전체 구조를 그대로 재현한 그림이 아닙니다.

평가 산점도는 작은 차이를 볼 수 있도록 두 축에 동일한 데이터 범위를 적용합니다. 막대그래프의 세로축은 0부터 시작합니다. `presentation.js`와 `presentation.css`는 데이터와 모델을 재학습하지 않고 표시와 탐색 방법을 개선합니다.

## 버블 거동

- **포밍 공정**: A(핵생성 전), B(핵생성), C(셀 성장)를 한 화면에 보여줍니다. B의 작은 기포와 C의 성장한 셀은 같은 위치·개수로 연결됩니다. 생성·성장 7초 재생과 슬라이더를 지원합니다. 흰 점은 가스 분자나 CBA 입자가 아니라 작은 기포핵입니다. 합체·소멸을 생략한 고화 전 공정 모식도이며 실제 해석 결과가 아닙니다. 셀 체적과 개수의 조건부 관계, 셀 합체, 해석 모델 및 출처는 펼침 설명에 있습니다.
- **압력·반지름**: 두 번째 화면입니다. 기준 셀과 같은 반지름의 두 비교 셀을 나란히 표시합니다. 가운데는 가스량을 유지하고, 오른쪽은 체적과 같은 비율로 가스량을 바꿉니다. 슬라이더·프리셋·재생에 따라 원 크기, 가스량과 압력이 함께 바뀝니다.
- **온도·밀도**: 수정된 온도 3조건의 코어밀도와 공통 시편 체적을 먼저 보여줍니다. 전체 그래프와 체적 계산은 펼쳐볼 수 있습니다.
- **해석값 비교**: 기존 81조건에서 선택한 두 조건의 반지름과 압력을 같은 눈금으로 비교합니다. 반지름은 최대값, 압력은 최대/평균 선택값입니다. 조건 설정과 추출 기준은 펼침 영역에 유지합니다.

압력·반지름 그림은 온도가 같은 이상기체의 상태 비교입니다. 체적은 반지름의 세제곱에 비례하며, 상대 압력은 상대 가스량을 상대 체적으로 나눈 값입니다. 반지름 약 0.794배인 셀에서 가스량이 같으면 압력 2배, 가스량도 절반이면 압력 1배입니다. 온도·압력·가스량·체적의 관계를 보여주며, 수지 점도·주변 압력·냉각을 포함한 실제 셀 성장 해석이 아닙니다. 가스 점과 셀 배치는 모식적 표현입니다.

근거: [NASA Glenn — Equation of State](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/equation-of-state/), [Autodesk — Microcellular foaming process](https://help.autodesk.com/cloudhelp/2023/ENU/MoldflowComm-CLC-Analyses/files/molding-processes/microcellular-inj-molding/MoldflowComm_CLC_Analyses_molding_processes_microcellular_inj_molding_Microcellular_foaming_process_html.html).

## 온도 3조건의 수정 데이터

CBA 1% · 속도 150 mm/s · V/P 90%를 고정하고 온도 190/205/220℃를 비교합니다. focus-data.js는 사용자가 제공한 수정 Google Sheet의 데이터_전치 A:I 및 X열, 18/45/72행을 2026-10-06에 읽은 스냅샷입니다. 코어밀도는 각각 0.7255, 0.7114, 0.6131 g/cm³입니다. 자동 동기화하지 않습니다.

원형 평판의 지름 108 mm, 두께 3.2 mm로 계산한 치수 기준 전체 체적은 29.314829369177076 cm³입니다. 코어밀도는 내부 폼의 밀도이며 셀 가스 밀도가 아닙니다. 전체 시편 체적과 개별 셀 체적을 구분합니다. 수정 시트의 값만 확인했으며, Moldflow 추출 위치·시점·통계 기준을 검증했다는 의미는 아닙니다.

기존 81조건의 공정변수별 그래프·상관분석·예측 모델을 유지합니다. 수정된 3조건은 별도로 추가했으며 기존 학습 데이터를 변경하지 않았습니다. 실제 반지름·압력이 같은 위치·시점의 값인지 확인되지 않아 두 값을 결합해 셀당 가스량을 역산하지 않습니다.
