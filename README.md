# capstone

폼사출 해석 결과를 비교하는 발표용 정적 웹사이트입니다.

## 추가 온도 3조건 비교 (2026-10-07)

사용자의 수정 시트에 따라 CBA 1% · 속도 150 mm/s · V/P 90%를 고정하고 별도 탭에서 온도 190/205/220℃를 비교합니다. `focus-data.js`는 `데이터_전치`의 A:I 및 X열, 18/45/72행에서 읽은 스냅샷입니다. 코어밀도는 각각 0.7255, 0.7114, 0.6131 g/cm³입니다. 기존 공정변수별 그래프, 전체 81조건 상관분석, 예측 모델 및 버블 거동 기능은 그대로 유지합니다. 수정된 3조건은 별도 데이터로 추가하며 기존 분석·학습 데이터는 변경하지 않습니다.

원형 평판의 지름 108 mm, 두께 3.2 mm로 계산한 치수 기준 체적은 29.314829369177076 cm³이며 세 조건에 공통입니다. 코어밀도를 전체 평균밀도로 간주하거나 전체 질량을 코어밀도로 나누지 않습니다. 수정 시트 값을 확인한 것이며, Moldflow 추출 위치·시점·통계 기준까지 검증했다는 의미는 아닙니다.

## 버블 거동

- `bubble.js`와 `bubble.css`가 시편 구조 모식도, 등온 이상기체 상태 비교, 실제 해석값 비교를 표시합니다.
- 원리 비교는 상대량으로 계산합니다. `P/P₀ = (n/n₀)/(V/V₀)`, `R/R₀ = (V/V₀)^(1/3)`이며 온도는 일정합니다.
- 가스량을 유지하고 체적을 절반으로 줄이면 상대 압력은 2입니다. 가스량과 체적을 모두 절반으로 줄이면 상대 압력은 1입니다.
- 애니메이션은 두 상태 사이의 설명용 전환이며, Moldflow의 셀 성장 방정식이나 실제 성형 시간 이력을 재현하지 않습니다. 입자 수와 시편 내부 셀 배치는 모식적 표현입니다.
- 버블 거동의 실제 결과 비교는 기존 `index.html`의 81개 행에서 조건을 조회합니다. 반지름 최대값과 압력 최대/평균값을 보여주며, 동일 위치·시점의 셀 상태로 결합하거나 셀당 가스량을 역산하지 않습니다.
- 원의 반지름에는 비교하는 두 조건에 동일한 축척을 적용합니다. 밀도나 압력에 따라 그림 크기를 임의 보정하지 않습니다.

근거: [NASA Glenn — Equation of State](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/equation-of-state/).

검증: `node check-bubble.cjs` — 상태 관계, 체적과 반지름, 전체 조건 조회, 탭 순서를 확인합니다.
